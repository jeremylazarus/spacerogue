# Spacerogue

A 2D top-down action roguelike set in space. Runs in the browser.

**Play:** https://jeremylazarus.github.io/spacerogue/

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

Pushes to `main` deploy automatically to GitHub Pages.

> Gameplay details are intentionally undocumented here. Discover them by playing.
